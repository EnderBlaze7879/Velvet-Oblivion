## First Steps

If you haven't yet, install the latest version of [Visual Studio Code](https://code.visualstudio.com/) (VSCode), and [Git](https://git-scm.com/). While Visual Studio Code is only needed for efficiency and ease-of-access, Git is required in order to pull and commit to repository branches. Make sure you login to GitHub on the both of these.

> [!NOTE]
> #### VSCode
> 1. Go to the Account icon in the bottom right
> 2. Select "Sign In to GitHub"
> 3. Follow the given steps from there
> #### Git
> For Git, you can find steps to login to your GitHub account [here](https://docs.github.com/en/get-started/git-basics/setting-your-username-in-git).

Once you have VSCode and Git installed and configured to your liking, open Git Bash. Type or paste ``` git remote add origin https://github.com/EnderBlaze7879/Velvet-Oblivion.git ``` and press Enter. 

Each environment is different depending on what you are contributing towards.
